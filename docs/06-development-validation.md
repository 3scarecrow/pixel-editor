# 点修 · 开发验收记录

日期：2026-10-08 · 版本：0.1.0 · 状态：首期开发完成，本地预览，尚未上线

## 交付范围

Next.js 网站首页与客户端编辑器已实现，可静态导出。像素编辑使用自研 Canvas 2D，PNG 解码、编码及 ZIP 打包在 Worker 中执行；图片不上传服务器。

- 单图编辑、多张独立图片管理；不同尺寸可同时导入，多图不自动播放动画。
- 主动选择图片子集进入动画；尺寸检查失败保持项目不变，未参与图片保留。
- 画笔及连续笔画、吸管、透明擦除、HEX/透明度、调色板、网格、缩放与平移、像素坐标/RGBA。
- 像素和结构操作统一撤销/重做；差分历史预算 64 MiB；图片视图独立保存。
- 动画帧复制、新建空白帧、排序、删除；独立播放游标、循环和 1–30 FPS；单帧禁用播放。
- 当前 PNG、全部图片 ZIP、动画帧 ZIP；保持原始尺寸及通道值，包括透明像素下的非零 RGB。
- 原子批次导入、错误文件反馈、容量保护、异步导出快照及未导出像素修改提示。

输入为静态 PNG，支持低位深灰度/索引色与 Adam7；拒绝 16 位和 APNG。宽高各不超过 1024，最多 100 张，总像素不超过 1600 万，单批次不超过 50 MiB。

## 性能采样

Chrome 155，1440×960，DPR 1；每种尺寸采样 3 次。实际页面未捕获运行时错误。记录见 artifacts/performance.json。

| 图片尺寸 | pointerdown 同步处理 | pointerup 同步处理 |
| --- | --- | --- |
| 64×64 | 0–0.2 ms | 0.6–0.7 ms |
| 256×256 | 约 0 ms | 0.5–0.6 ms |
| 1024×1024 | 0–0.2 ms | 0.7–1.1 ms |

数据为事件同步处理耗时，受计时精度影响；不代表完整绘制延迟或帧率。第二次 requestAnimationFrame 回调约 27–29 ms，也不应解读为卡顿阈值。样本量有限，不能据此承诺所有设备性能。完整 1600 万像素项目峰值内存、20 帧 256×256 的长时间稳定性与低端设备仍需发布前专项压测。

## 运行与后续边界

运行命令见 README。当前预览使用 out/ 静态产物；修改源码后须重新构建。

项目、撤销历史和动画设置仅在本次页面会话存在，没有自动恢复。刷新前的浏览器提示只针对尚未导出的像素修改；帧顺序由动画 ZIP 的编号体现，FPS 不写入 PNG/ZIP。暂不提供 SVG、GIF、APNG 输出、项目文件、移动端适配、账号和云存储。

上线前需确定域名与 HTTPS 静态托管，验证真实部署下的路由、Worker 及下载行为，并完成目标设备兼容性及上限项目压力测试。
