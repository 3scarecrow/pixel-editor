# 点修 · 发布前测试报告

日期：2026-10-08。测试对象为当前 out/ 生产静态产物。此次仅测试与记录，未修改产品实现，也未部署。

## 结论

发现一个已复现的发布阻塞问题：编辑器内部返回首页的导航会直接丢弃未导出的像素修改。建议先修复并补充回归测试，再进入部署准备。

## 问题与验收缺口

### P1：返回首页未保护未导出的编辑

复现：从首页进入编辑器 → 导入 PNG → 用画笔修改像素（撤销按钮可用）→ 点击左上角“点修”返回首页 → 再打开编辑器。

实际结果：离开时没有确认弹窗，重新进入编辑器为空项目，刚才的修改与历史丢失。预期：存在未导出修改时，应确认离开，或保留可恢复的会话；选择继续编辑应留在原项目。

原因：现有 beforeunload 仅处理刷新/关闭等页面卸载。Logo 使用 Next.js 客户端导航，编辑器组件卸载而不会触发该事件。定位：src/components/Editor.tsx 的首页 Link 和 beforeunload 监听。

证据：artifacts/navigation-audit.json 中 edited=true、dialogs=[]、lostWithoutConfirmation=true、backToEditorIsEmpty=true。建议还覆盖浏览器后退等站内离开路径，避免只补一个 Logo 入口。

### Safari / Edge 实机兼容性尚未验收

Chrome、DPR 2 Chrome 和 Firefox 自动化验证已通过。本机没有当前测试驱动匹配的 WebKit 包，早期驱动/浏览器协议不兼容；没有得到本轮 Safari 结果。这是验收缺口，不能归为已确认的应用故障。实际 Safari 与 Edge 稳定版仍需上线前验证。

移动端编辑仍属于首期范围之外；此次只检查移动首页布局，不意味着编辑器支持手机操作。
