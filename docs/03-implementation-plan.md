# 点修 · 实施与验证计划

版本：0.4 · 日期：2026-10-08

## 1. 开发顺序

| 阶段 | 交付 | 完成条件 |
| --- | --- | --- |
| 1. 技术验证 | Next.js 客户端/Worker 构建验证、Dotting 适配评估、PNG 编解码选型、Canvas 性能测量 | 预渲染与 Worker 加载正常；半透明及透明像素往返一致；确定编辑组件与内存保护阈值 |
| 2. 单图闭环 | 导入、缩放、平移、网格、画笔、吸管、擦除、历史、导出 | 单图验收通过，坐标映射与像素保真可靠 |
| 3. 多图与动画 | 不同尺寸图片管理、主动动画转换、帧管理、跨模式历史、动画预览、ZIP | 多帧顺序、播放与导出一致，批次失败无部分写入 |
| 4. 发布准备 | 错误反馈、超限保护、修改提示、浏览器验证 | 支持浏览器验收通过，部署产物可用 |

先完成像素保真验证，再推进完整界面，避免后期发现浏览器编解码流程无法满足验收。此计划未承诺工期；技术验证结果会影响选型与开发量。

## 2. 界面布局

- 顶部：点修品牌、图片/动画模式入口、导入、新建、撤销、重做、导出。
- 左侧：画笔、吸管、橡皮擦、平移、颜色及透明度。
- 中央：可缩放平移的像素画布。
- 右侧：仅动画模式显示独立预览与 FPS；图片模式释放空间给画布。
- 底部：单图隐藏列表；多图展示图片列表、文件名和尺寸及“作为动画帧编辑”；动画模式展示帧列表与操作。
- 状态区：图片尺寸、选中帧、像素坐标、缩放比例及任务进度。

初始页面用简短提示引导导入。解码、导出任务显示进度或工作状态；错误消息指出出错文件及解决方法。

## 3. 验证策略

| 层级 | 重点 |
| --- | --- |
| 核心单元测试 | 坐标边界、连续笔画、重复像素差分、RGBA 读写、历史分支、帧深拷贝 |
| 编解码集成测试 | RGB/RGBA、索引色、灰度、透明与半透明、完全透明下非零 RGB、损坏与不支持 PNG |
| UI 端到端测试 | 导入编辑导出闭环、不同缩放下编辑、不同尺寸图片切换、模式转换、帧排序与删除撤销、引用一致性、批次失败、异步过期结果 |
| 人工浏览器验收 | 高 DPI、边缘清晰、拖出画布、下载、后台恢复、颜色输入、快捷键及错误反馈 |
| 性能验证 | 典型像素图与设计上限附近项目，记录导入耗时、交互延迟、导出耗时和峰值内存 |

像素保真比较使用独立测试读取器或已知 RGBA 样本作为基准，避免只用同一编解码器自测而遗漏共同缺陷。文件压缩结果不同不视为失败。

性能目标初值：常见 64×64、128×128、256×256 图片的编辑在下一次前台画面刷新中可见；20 帧、256×256 的动画稳定预览。记录测试机器、浏览器和结果后再给出可承诺指标。

## 4. 风险与处理

| 风险 | 处理 |
| --- | --- |
| Canvas 往返改变透明颜色 | 直接 PNG ↔ RGBA 编解码；Canvas 仅显示 |
| 色彩配置使显示与存储值不同 | 明确按原始通道值编辑，展示颜色值；色彩管理后续独立设计 |
| 多帧和历史占用过多内存 | 输入限额、历史预算、缓存释放、逐帧编码；技术验证测峰值 |
| 拖动速度快导致漏点 | 整数线段插值与 pointer capture |
| 编辑与动画争抢帧选择 | 播放游标独立于选中帧 |
| 导出和新编辑存在竞争 | 导出固定快照，按修订判断是否仍有未导出修改 |
| 刷新丢失编辑 | 修改提示、清晰说明本地临时状态；后续项目恢复 |

## 5. 开发前默认决策

首期只支持 PNG 输入与 PNG/ZIP 输出，不实现 SVG、GIF、APNG、账号及云存储。统一帧率，不设置每帧时长。动画帧尺寸不一致时拒绝导入，不自动裁切或缩放。默认面向桌面鼠标操作。默认图片模式允许不同尺寸；主动动画转换及动画追加才要求尺寸一致。

这些默认决策已写入需求与架构，后续若调整，应同步修改验收标准与实现计划。

## 6. 技术验证交付

- 已完成 Dotting 最小验证，进入自研 Canvas 核心验证：导入外部 RGBA、单笔差分事件、帧切换、历史控制及像素保真。
- 优先验证 fast-png 与 fflate 的浏览器 Worker 集成；锁定通过测试的版本，记录许可证和依赖。
- 验证 `/` 与 `/editor` 构建、直接访问、预渲染和静态导出，无服务端浏览器 API 报错。
- 测量帧绘制、缩放、交互延迟和内存；形成复用选型记录后进入完整开发。

框架组合已确定；Dotting 2.1.18 最小验证已完成，因大图同步开销和历史接管代价，已确认采用精简自研 Canvas 核心；具体依据见 [验证报告](05-dotting-validation.md)。PNG/ZIP 依赖与首期功能已验证；生产静态构建已完成，尚未上线。此阶段不以 README 功能列表替代实际适配测试。

## 7. 两种模式的专项验收

单图隐藏动画及列表；多图不自动启用动画；不同尺寸独立导入正常。转换失败不修改项目；子集转换保留其他图片；模式切换和撤销保留已有修改与引用。单帧禁用播放；离开动画模式停止调度；普通模式追加图片不自动进入序列。UI 命名、导入和导出范围随模式变化。

单图闭环、多图管理、主动动画模式、帧管理、全局历史及 Worker PNG/ZIP 导出已完成。核心测试、浏览器测试、实际界面截图与性能采样见 [开发验收记录](06-development-validation.md)。发布阶段仍需确定域名与托管平台，并补充目标设备上的实际 Safari/Edge 验收；完整上限项目峰值内存与长时间动画稳定性尚未作发布级压测。
