# 点修 · 需求说明

版本：0.4 · 日期：2026-10-08 · 状态：首期已实现，验收结果见开发验收记录

## 1. 产品目标

产品名称：**点修**。功能描述：在线像素图片编辑与动画修整。

用户导入 AI 生成的像素图，在放大网格中精确修改像素颜色，再以原始尺寸导出 PNG。默认按独立图片编辑；仅在用户明确选择动画编辑时，将图片组织为帧并预览。

核心原则：未经编辑的像素保持不变；编辑不引入抗锯齿或自动缩放；透明像素可编辑；所有处理在浏览器内完成。

## 2. 首期范围

| 功能 | 要求 |
| --- | --- |
| 导入 | 支持单张或多张 PNG，读取实际尺寸；解码失败时显示具体文件与原因 |
| 工作模式 | 默认图片编辑；显式切换动画编辑，不按导入数量、文件名或尺寸自动判断 |
| 图片尺寸 | 图片模式允许不同尺寸，每张图片独立保存；动画模式所有帧尺寸一致；不自动缩放 |
| 画布 | 缩放、平移、网格开关、像素坐标显示；放大后边缘清晰 |
| 绘制 | 单像素点击、拖动连续绘制；一次拖动作为一次撤销操作 |
| 颜色 | 吸管取色、HEX 输入、透明度输入；支持 RGBA |
| 擦除 | 将目标像素设为透明，支持连续拖动 |
| 历史 | 项目级撤销、重做，覆盖绘制、图片/帧管理和模式转换；切换编辑对象不清空历史 |
| 图片管理 | 单张时隐藏底部列表；多张时展示文件名、尺寸、修改标记，支持切换、复制、删除、排序及多选 |
| 帧管理 | 动画模式提供缩略图、添加空白帧、复制、删除、排序；非空项目至少保留一帧 |
| 动画 | 仅动画模式显示预览与播放；统一帧率默认 8 FPS，范围 1–30；单帧时禁用播放并提示添加更多帧 |
| 导出 | 当前图片/帧 PNG；全部图片/帧 PNG 打包为 ZIP；独立图片保留规范化文件名并处理重名，动画使用连续帧序号 |
| 本地处理 | 不发送图片内容到服务器；不需要账号 |

画布显示采用棋盘格表示透明背景，棋盘格和网格不写入导出图片。默认颜色不透明；擦除归一化为 RGBA(0,0,0,0)。

## 3. 交互流程与模式转换

### 图片编辑（默认）

1. 打开点修，导入一个或多个 PNG；不自动进入动画模式。
2. 每张图片保留原始尺寸。单张时聚焦画布，隐藏列表、动画预览与 FPS；多张时底部展示“图片列表”。
3. 按文件名自然排序导入，选择图片后独立编辑。缩放和平移按图片保存，切换时恢复。
4. 导出当前图片，或将全部独立图片打包下载。

### 主动进入动画编辑

- 页面顶部提供“图片编辑 / 动画编辑”模式入口；多图列表提供“作为动画帧编辑”。
- 未选择图片时使用全部图片；选中子集时只使用该子集，转换前明确显示数量和顺序。
- 转换前校验尺寸，列出不一致文件及尺寸；校验失败不修改状态、不自动裁切或缩放。
- 按列表顺序组成动画帧并保留像素修改；未参与的图片保留在独立图片工作区。首期同一会话最多一个动画序列。
- 动画模式显示帧列表、独立预览及 FPS；切换模式不丢失数据或重置历史。
- 动画入口在未导入图片时可进入空状态，提示导入帧；一帧可编辑，但播放禁用并提示“添加更多帧后可预览动画”。
- 图片模式下，动画序列成员仍作为独立图片可访问；新增图片不自动加入已有动画。
- 已有动画时，添加帧通过动画模式的“导入帧”完成；图片列表的转换入口改为“加入动画帧”，执行前校验尺寸，已有成员不重复加入。

### 公共行为

已有项目再次导入：图片模式追加独立图片；动画模式明确追加帧，要求与动画尺寸一致。批次先整体校验，失败不部分导入。

提供“新建项目”；存在未导出修改时提示确认。刷新和关闭页面提示可能丢失修改，但浏览器不保证一定展示提示。

播放游标与选中编辑帧分离。离开动画模式停止播放并取消调度，保留帧顺序和 FPS；返回时默认暂停。

图片列表删除图片时同步移除其帧引用；若会造成已有动画零帧，阻止并提示至少保留一帧。动画模式删除帧只移除序列引用，源图片仍保留。复制产生独立像素副本。空白帧使用动画公共尺寸；动画模式不提供任意尺寸调整。

## 4. 首期限制与兼容性

- 默认设计上限：单张图片/帧宽高各不超过 1024 像素；总像素数不超过 1600 万；最多 100 张图片（动画引用不重复计数）；批次文件总大小不超过 50 MiB。这些是保护性初值，开发时通过性能验证调整。
- 历史内存预算初值为 64 MiB，超出时移除最早记录并提示；单次操作超过预算时，执行前说明该操作无法撤销。
- 首期面向桌面浏览器，覆盖开发时的 Chrome、Edge、Safari 稳定版；触屏适配、移动端与离线能力后续评估。
- 首期面向静态、8 位通道 PNG；动画 PNG 明确拒绝作为单帧输入；16 位通道 PNG 提示不支持，避免静默损失精度。
- 导出保证尺寸和解码后 RGBA 像素数据，不保证文件字节、压缩方式、调色板、色彩配置或其他元数据原样保留。

## 5. 验收标准

1. 修改坐标 (x,y) 后，仅该像素发生指定变化；拖动路径按预定算法连续覆盖，无断点。
2. 在不同缩放及平移条件下，点击边界不会写入相邻或越界像素。
3. 对受支持的 PNG，无编辑导入再导出后，尺寸及所有解码后 RGBA 值一致，包括透明像素下的 RGB 值。
4. 网格、背景棋盘格和预览缩放均不影响导出内容。
5. 一次完整绘制、图片/帧管理和模式转换可以撤销、重做；撤销后产生新修改清空重做记录。
6. 仅动画模式运行播放调度，按帧列表顺序循环；单帧禁用播放，后台暂停，返回前台重新计时。
7. PNG 和 ZIP 可重新读取；ZIP 中的文件数量、命名及像素与对应图片/帧一致。
8. 图片模式允许不同尺寸；动画模式拒绝尺寸不一致批次；损坏、不支持或超限批次不产生部分导入。
9. 图片内容不产生网络请求；导出失败时保留编辑状态并允许重试。

10. 导入单张及多张独立图片均不显示动画区域；主动转换后保留已有修改，失败转换不改变工作区。
11. 模式切换保留序列、FPS、当前对象和项目历史；图片删除与动画引用始终一致。

## 6. 后续范围

洋葱皮、精灵图导出、GIF/APNG 导出、项目保存与恢复、自动恢复、批量同色替换、选区工具。

SVG 暂不实现。像素矩形 SVG 在较大图片上体积较大；如果有矢量交付需求，再决定透明度、矩形合并和尺寸规则。
