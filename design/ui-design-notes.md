# 点修 · UI 设计 v2

日期：2026-10-08 · 桌面端 · 自研 Canvas 2D 方案

品牌：点修。首页功能描述为“在线像素图片编辑与动画修整”，编辑器内只显示“点修”。名称尚未进行域名和商标核查。

## 默认图片模式

顶部：品牌、图片编辑/动画编辑模式入口、项目名称菜单（包含新建）、导入、撤销重做、导出。画布占据左侧工具面板之外的主要空间，不显示右侧动画区域。

左侧：画笔、吸管、橡皮擦、平移，颜色与透明度、常用色板。中间：当前文件名和尺寸、网格、缩放、适应画布。

单图时隐藏底部列表，扩大画布。多图时显示“图片列表”，缩略图含文件名、独立尺寸、修改标记；提供切换、多选、复制、删除、排序，以及“作为动画帧编辑”。未选择时对全部图片操作，选择子集时显示转换数量。已有动画时入口改为“加入动画帧”。

当前 UI 示意为多张独立图片，使用不同内容和尺寸，明确区别于连续帧。

## 动画模式

模式入口高亮“动画编辑”；导入按钮为“导入帧”。右侧显示独立动画预览、播放暂停、循环与 FPS；底部“动画帧”按序号显示，可添加空白帧、复制、删除、排序。

进入前检查帧尺寸一致；不一致时列出文件名与尺寸，不自动裁切。单帧显示“添加更多帧后可预览动画”，播放禁用。空动画显示导入提示。切回图片模式停止播放，保留序列和图片修改。

## 导出与状态

导出按钮默认当前图片/帧 PNG；下拉菜单按模式显示全部图片或全部帧 PNG/ZIP。图片模式保留文件名并处理重名，帧模式使用顺序编号。帧列表顺序代表时间顺序，独立图片列表顺序只影响列表及打包顺序。

状态栏显示坐标、RGBA、本地处理提示与未导出修改。颜色、透明棋盘格和网格的表现不得改变源像素。
