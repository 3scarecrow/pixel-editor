# 点修 · 首页视觉设计 v3

日期：2026-10-08。仅设计图，尚未修改页面代码。

主色采用浅荧光绿 #C8FF85，搭配近黑背景、炭灰面板与暖白文字。按钮使用浅绿实色与深色文字，导航右上角“打开编辑器”为明确按钮。

首屏展示同一像素鱼的 AI 原图与修整结果，只修正错误颜色，保持尺寸、轮廓及姿态一致。对比区配放大像素网格，明确呈现修改前后；最终实现素材应使用真实原图和真实编辑结果，生成图只说明布局。

拟议动效：首屏文字错峰渐入（300–500 ms）；对比滑杆可拖动，未操作时演示一次错误像素修正，用户操作后停止；背景柔和呼吸光（6–8 s）；步骤区进入视口时短距离渐入。按钮悬停有轻微亮度与位移反馈。支持 prefers-reduced-motion，禁用自动演示、呼吸光和位移动效，保留静态对比及手动拖动。不持续运行吸引注意的闪烁或大幅运动。

页面顺序：导航 → 产品主张与修整前后对比 → 三步使用流程 → 精确编辑、多图管理、主动动画预览 → 本地处理与及时导出提示 → 页脚。动画预览仍仅在用户主动选择同尺寸图片作为连续帧时启用。

图中动效标注用于评审，不应作为网站实际文案。位图无法播放真实网页动画。使用内置 image_gen 生成，提示词见 ui-prompt-home-v3.txt。
